# 3 分钟演示讲稿

## 0:00–0:25 问题

“重要会议前，我们要查对方最近发生了什么，但搜索链接很多，AI 摘要又可能混入旧信息。BriefSignal 帮你准备一页会议简报，而且能逐条查看证据。”

## 0:25–0:50 输入

展示公司/人物切换、会议时间、官方域名、会议目标和中英文输出选项。解释窗口是会议前 30 天，未来会议只能使用当前已知信息。

## 0:50–1:35 结果与证据

展示三个部分：发生了什么、对会议的意义、可以问的问题。点开 S1，显示来源、发布时间、抓取时间及原文片段。解释“事实”和“AI 对相关性的解释”分开。

如果演示的是 Northstar Robotics，要先说：“这是虚构的固定演示案例，不会调用外部 API。”只有在实时调用成功时，才能说这是 Tavily 和模型刚刚产生的研究结果。

## 1:35–2:10 最能体现差异的部分

进入 Evidence → Excluded。展示过期来源、无发布日期来源、未来来源被排除。解释没有找到证据时会明确保留空缺，不会用一个看起来合理的故事补齐。

## 2:10–2:35 技术

“Tavily Search 负责发现动态，Extract 负责获取证据，大模型整理事实和问题。最后用确定性规则检查时间、来源 ID 和原文引述。我们不会把可追溯引用宣称为事实已经独立核实。”

## 2:35–3:00 交付与边界

打印一页 PDF，展示 JSON 导出和研究轨迹。介绍已通过的离线和浏览器测试，并如实说明真实联调状态。下一阶段计划是更多真实案例评测、冲突证据检测和用户反馈，不把计划说成已完成功能。
